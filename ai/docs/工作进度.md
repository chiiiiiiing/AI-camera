## 当前阻塞

1. Android 工程已接 ONNX；本机完整 Gradle 构建当前受回环连接错误阻塞，需要在正常构建环境验收。
2. 缺目标 Android 设备的延迟、内存、发热、连续相机帧稳定性指标。
3. 训练集只有 579 条，且类别不均衡；`plant_still_life` 和 `urban_landscape` 等类别覆盖偏少。
4. 24 张裁剪候选未处理，暂不进入 accepted manifest。
5. 外置盘小文件 I/O 明显偏慢，生成 student embedding 和重建索引时会拖慢落盘。

## 下一步

1. 把 `App技术设计/09-AI接入包说明.md` 交给 Android 队友，按 ONNX Runtime Mobile 接 static int8 ONNX 和模板索引。
2. 在目标 Android 设备上验证单帧 embedding 延迟 p50 <= 80ms、p90 <= 150ms，并记录内存、发热和连续预览稳定性。
3. App 侧按 500ms-1000ms 抽帧或画面变化触发 embedding，并用 top5 + 规则重排，不只依赖 top1。
4. 补充更多同 schema 素材，优先补齐 portrait、plant、urban 等弱类别；目标至少把可训练模板提升到 3000+。
5. 达到质量和端侧性能阈值后，再决定是否把 new_batch 合并为正式索引。
