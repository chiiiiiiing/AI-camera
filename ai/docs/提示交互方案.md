# 拍摄提示交互方案

## 核心原则

不能只用“目标点”指导用户。目标点无法区分用户应该原地转手机，还是应该横向走一步、靠近、后退、蹲低或抬高手臂。

取景器提示分为六层，每层只表达一种动作。

## 六层提示

| 层 | 作用 | 示例文案 |
|---|---|---|
| 姿态环 | 原地转手机、抬/压镜头、校水平 | “原地向右转一点” |
| 机位轨迹 | 移动身体或手机位置 | “向右走半步，不要转手机” |
| 自动变焦 | 软件平滑缩放画面 | “自动放大一点，让人物更突出” |
| 构图锚点 | 最终构图对齐 | “把主峰放到右下交叉点” |
| 人像姿势层 | 被拍的人怎么站、怎么摆 | “左手自然弯一点” |
| 文字建议 | 当前最重要的一步 | “先后退一点，留出天空” |

## 显示节奏

- 每屏只突出一个主动作。
- 偏差大时先提示姿态或机位，不急着显示目标点。
- 接近模板构图后，再突出构图锚点。
- 人像姿势最多同时提示 1-3 个关键关节。
- 达标必须连续稳定 N 帧后才显示绿色完成态。

## 自动变焦边界

自动变焦只解决画面尺度，不解决透视关系。

适合自动变焦：

- 主体略小，需要轻微放大。
- 风景太满，需要轻微缩小。
- 静物边缘杂物太多，需要小幅裁切。

不适合自动变焦：

- 需要改变透视，应提示用户移动机位。
- 数码变焦会明显损失画质。
- 主体检测不稳定。
- 用户正在手动缩放。

## 冲突处理

- 姿态环和机位轨迹不能给相反指令。
- 系统不确定是转动还是平动时，用文字提示“先向右试半步”。
- IMU 不稳定时，隐藏姿态环动画，仅保留文字。
- 画面中多人时，先给整体站位，再给单人姿势。

## 输出给 App 的最小信息

AI 引擎每帧输出：

- 当前主提示类型。
- 主提示文案。
- 姿态方向和强度。
- 机位方向和强度。
- 推荐缩放倍率和置信度。
- 构图锚点、主体框、辅助线。
- 人像目标关键点和关节提示。
- 当前综合得分和稳定状态。
