## 归档原则

旧交接 prompt、团队任务拆分、远程开发说明、历史拒绝清单、重复流程文档和过时 App 合订文档不再维护。需要追溯时看 Git 历史。

## 阅读顺序

1. 先读 `工作进度.md`。
2. 如果需要用户输入，读 `需要用户完成的任务.md`。
3. 给视觉模型交接标注时读 `视觉标注执行Prompt.md`。
4. 选商业 embedding 路线时读 `Embedding模型路线.md`。
5. 做 Android App 接入时读 `../App技术设计/09-AI接入包说明.md`。
6. 做 AI 技术实现时读 `技术设计与工作流程.md` 和 `模板索引端侧接入方案.md`。
7. 做产品/交互判断时读 `产品需求理解.md` 和 `提示交互方案.md`。

## 维护规则

- 不再写长篇接手 Prompt。
- 不把已完成工作保留在用户待办里。
- 大段历史只保留在 Git 历史中，文档只写当前结论。
