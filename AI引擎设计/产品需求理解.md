## 一、产品是什么

一款 **Android 手机相机 App**。用户打开它拍照时，取景器上会叠加 AI 实时生成的**视觉引导**（目标点、虚线人形、构图线），告诉用户"相机往哪移、模特站哪、摆什么姿势"。相机移动不再用箭头，而是在画面显示一个目标点，用户将相机中心对准目标点即可。让不会拍照的普通人也能拍出构图好、姿势自然、光线合适的照片。覆盖**人像、风景、静物**三大摄影类型。

一句话：**拍照小白的实时 AI 摄影教练。**

---

## 二、目标用户

| 用户画像 | 特征 |
|---|---|
| 拍照小白 | 不懂构图、光圈、曝光；手机的"专业模式"从来没用过 |
| 社交分享者 | 想要朋友圈/小红书高赞照片，但自己拍不好 |
| 替人拍照者 | 帮朋友/家人拍照时总被吐槽"拍得好丑" |
| 单人自拍困难户 | 没人帮拍，自己举着手机不知道怎么站位 |

**摄影类型覆盖**：
- 人像摄影（单人、情侣、合影）
- 风景摄影（山川、海景、城市天际线、日落等）
- 静物摄影（美食、花卉、小物件等）

**我认为你们不做**：
- 摄影师/摄影爱好者（他们不需要指导）
- 专业后期修图（本产品只管拍摄，不管修图）
- 视频拍摄指导（只做静态拍照）

**✅ 已确认：以上判断完全正确。**

## 三、核心使用场景（我理解的故事板）

### 场景 1：旅游打卡
> 小张和女朋友去海边旅行。女朋友站在沙滩上，小张举起手机。AI 识别出"海滩+日落"场景，取景器上出现：
> - 一个绿色虚线人形，示意女朋友往右边站两步，右手搭在腰间
> - 一个目标点显示在画面右下，小张把相机中心对准它，自动形成低角度构图
> - 九宫格线显示人物应该在右下交叉点
> - 底部文字："相机放低到膝盖高度，让她的轮廓映在晚霞里"

### 场景 2：街拍
> 小王在咖啡馆门口想给朋友拍一张。AI 识别"城市街道+建筑"，引导：
> - 虚线人形示意朋友侧身靠在墙上
> - 目标点显示在画面左侧，小王移动相机将中心对准目标点，为朋友视线方向留出空间
> - 引导线利用街道的延伸感做纵深构图

### 场景 3：多人合影
> 一家人站好等着拍全家福。AI 识别"多人合影"：
> - 虚线框标记每个人的站位调整
> - 提示"中间的人稍微往前半步，形成一个弧形"
> - 检测到有人被遮挡："最右边的人请往左靠一点"

### 场景 4：室内暗光
> 朋友在餐厅窗边。AI 识别"室内+窗光"：
> - 目标点引导把朋友框在窗边侧光位置
> - 提示"让人物面向窗户，光线会很柔和"

### 场景 5：风景拍摄
> 小明在黄山看日出。AI 识别"山景+日出"场景：
> - 九宫格线标记地平线应该放在上三分之一处
> - 箭头引导相机往右转一点，把主峰放在右下交叉点
> - 底部文字："地平线放画面上方三分之一，让云海占更多画面"

### 场景 6：静物拍摄
> 小红在餐厅拍一道精致的甜品。AI 识别"美食+桌面"：
> - 提示"从上方 45 度俯拍，利用窗边的自然光"
> - 目标点引导手机移到正上方 45 度位置，构图线标记盘子放在画面中央
> - 检测到光线不足："靠近窗户，用自然光拍更好看"

## 四、功能需求清单

### 4.1 拍照前引导（核心功能，AI 负责）

| 编号 | 功能 | 描述 | 我理解的对吗？ |
|---|---|---|---|
| F1 | 实时构图引导 | 目标点引导用户移动相机，将画面中心对准目标点即获得最佳构图 | ✅ |
| F2 | 实时姿势引导 | 虚线人形叠加在取景器上，引导被摄者调整姿势 | ✅ |
| F3 | 构图辅助线 | 九宫格、地平线、引导线等叠加显示 | ✅ |
| F4 | 自然语言建议 | 屏幕底部显示口语化的拍照建议（如"往左走一步，相机放低"） | ✅ |
| F5 | 场景自动识别 | 自动识别当前场景（海滩、城市、室内等），匹配最佳构图模板 | ✅ |
| F6 | 对齐评分 | 实时显示综合对齐得分（>85% 变绿 = 可以拍了） | ✅ 要做 |
| F7 | 多人支持 | 检测画面中多人，分别给出姿势建议 | ✅ 要做 |

### 4.2 拍照后（我不确定做不做）

| 编号 | 功能 | 描述 |
|---|---|---|
| F8 | 拍照评分 | 拍完后给照片打分，指出哪里好哪里不好 |
| F9 | 照片对比 | 将拍的照片与参考模板并列展示 |
| F10 | 拍照历史 | 保存拍摄记录和评分历史 |

**✅ 已确认：F8-F10 不在第一版做。**

### 4.3 系统能力

| 编号 | 功能 | 描述 |
|---|---|---|
| F11 | 离线运行 | 全部 AI 推理在手机端侧执行，不需要网络 |
| F12 | 模式自动选择 | 根据手机性能自动选择模型档位（标准/轻量/极简） |
| F13 | 模板库 OTA 更新 | 无需更新 App 即可更新摄影模板库 |

| 类别 | 要求 | 来源 |

## 六、我应该澄清的问题

以下是我不太确定的地方，请逐一回答：

### Q1: 后置还是前置摄像头？ ✅
后置为主，也支持前置自拍。前置时需要镜像处理引导方向。

### Q2: 摄影类型范围？ 🔧
**人像 + 风景 + 静物**，三类都做。画面中有人时给姿势引导+构图引导，无人时只给构图和光线引导。

### Q3: 引导对象是拍的人还是被拍的人？ ✅
两者都引导：箭头引导拍摄者移动相机，虚线人形引导被摄者调整姿势。

### Q4: 声音播报做不做？ ✅
不做语音播报，仅视觉引导。

### Q5: 儿童/宠物做不做？ ✅
第一版不做，只覆盖成人人像。

### Q6: 是否有快门触发逻辑？ 🔧
**始终由用户手动按快门**，不做自动触发。

### Q7: 与系统相机的关系？ ✅
独立的第三方相机 App。

### Q8: 成品照片存储 🔧
**直接存系统相册**。

### Q9: Android 独占还是后续会做 iOS？ ✅
Android 优先，iOS 不在第一版。

## 七、用户旅程图（我理解的典型使用流程）

```
1. 用户打开 App
   │
2. 相机启动，AI 引擎初始化（1-2 秒，显示加载动画）
   │
3. 用户对准拍摄对象
   │
4. AI 自动识别场景（例如"海滩日落"）
   │  └─ 外圈检索匹配最佳模板
   │
5. 取景器上出现视觉引导（实时，30fps）
   ├─ 目标点：指示相机应对准的位置（画面中心的移动目标）
   ├─ 虚线人形：目标姿势骨架（人像时）
   ├─ 构图辅助线：九宫格、地平线
   └─ 底部文字：口语化建议
   │
6. 用户和被摄者根据引导调整
   │  └─ 对齐得分逐步升高
   │
7. 得分变绿（>85%）→ 用户按快门拍照
   │
8. 照片保存到相册
   │
9. 继续拍下一张 / 回到步骤 3
```

## 八、与竞品的差异（我的推测）

| 竞品 | 他们做什么 | 我们不同在哪 |
|---|---|---|
| 原生相机 AI | 场景识别自动调色 | 我们是**拍摄前主动引导**，不是拍完后自动优化 |
| VSCO / Lightroom | 后期滤镜和编辑 | 我们是**拍的时候教你怎么拍**，不是拍完再修 |
| Camera51 | 构图辅助 | 只有构图线，没有**姿势引导 + 场景语义** |
| Sony 相机 App | 引导线 + 水平仪 | 纯物理辅助，没有 AI 理解场景内容 |

我们的核心差异：**像有一个摄影师朋友站在你旁边，实时告诉你怎么拍。**
