# 模板索引端侧接入方案

## 当前索引产物

正式索引目录：`tools/preprocessed/template_index.visual-clean/`

| 文件 | 用途 |
|---|---|
| `templates.embeddings.f32` | 104 条 256 维 float32 embedding |
| `templates.keys.json` | 数值 key 与模板信息映射 |
| `templates.metadata.jsonl` | 端侧可用的模板元数据 |
| `templates.usearch.idx` | Python USearch 原型索引 |
| `templates.usearch.json` | USearch manifest |
| `templates.quality_report.json/md` | 检索质量评估 |

Android 首发候选索引目录：`tools/preprocessed/template_index.new_batch.student-tiny-cnn-v9-static-int8-onnx-512/`

| 文件 | 用途 |
|---|---|
| `templates.embeddings.f32` | 728 条 512 维 float32 embedding，来自 v9 static int8 ONNX |
| `templates.keys.json` | 数值 key 与模板信息映射 |
| `templates.metadata.jsonl` | App 端可用的模板元数据 |
| `templates.usearch.idx` | Python USearch 原型索引 |
| `templates.usearch.json` | USearch manifest |
| `templates.quality_report.json/md` | static int8 ONNX 检索质量评估 |

注意：两个索引维度不同，不能混用。`visual-clean` 是 104 条正式非人像库；v9 static int8 ONNX 是 Android 首发模型候选库，尚未合并为正式库。

## 加载约定

正式库 App 侧把索引文件放到：

```text
<model_dir>/template_index.visual-clean/
```

`engine_init` 仍只接收 `model_dir`，C++ 内部按固定相对路径查找模板索引。Android assets 不能直接作为普通文件路径，App 首次启动应复制到 app-private files 目录。

Android v9 候选包建议放到：

```text
<filesDir>/ai/v9/
  student_model.static_int8.onnx
  android_onnx_runtime_manifest.json
  android_runtime_config.json
  template_index/
```

当前仓库没有 Android App 工程，无法在本仓库内验证 assets 复制和相机链路。

## 当前 C++ 实现

- 加载 `templates.keys.json`。
- 加载 `templates.metadata.jsonl`。
- 加载 `templates.embeddings.f32`。
- 校验 count、dimension、key 顺序、metadata 顺序、L2 normalize。
- exact dot-product topK fallback。
- `engine_get_status_json` 暴露索引状态。

## 仍需接入

- 真实 USearch C++ backend。
- Android arm64-v8a 编译验证。
- App-private asset 复制和 native 加载验证。
- 实时 frame embedding 接入 Android App。
- 目标 Android 设备 p50/p90、内存、发热验证。

## 查询策略

不要直接信 ANN top1。当前质量评估显示 top5 召回更可靠。

建议流程：

1. embedding 检索取 top8/top10。
2. 先按 `photo_type` 硬过滤。
3. `scene_category` 高置信时过滤，否则作为加分项。
4. 构图字段和光线字段做规则重排。
5. top1/top2 margin 太小时保持当前模板，避免频繁跳变。
6. 人像模板上线前，人像查询不能用非人像模板冒充。

## 错误处理

- 索引目录缺失：引擎降级启动。
- manifest 无效：拒绝半加载，状态 JSON 写明原因。
- dimension 不匹配：拒绝加载。
- USearch 加载失败：尝试 exact fallback。
- fallback 也失败：模板检索不可用，但 engine 不崩溃。
