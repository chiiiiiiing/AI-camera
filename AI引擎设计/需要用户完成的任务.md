## 1. Android 端侧验证条件

已确认：

- 首发平台：Android。
- 用户只负责 AI 模型训练，不负责 App 搭建。
- 单帧 embedding 延迟目标：p50 <= 80ms，p90 <= 150ms。
- 量化后模型大小目标：<= 5MB。
- 相机预览建议 500ms-1000ms 抽帧或画面变化触发，不每帧跑 embedding。
- 第一版推荐使用 top5 + 规则重排，不只依赖 top1。
- 当前最佳 student 候选更新为 `tiny_cnn_v9_wide_topk_siglip2_512`。
- Android runtime 路线已先按 ONNX Runtime Mobile 推进。
- v9 FP32 ONNX 与 static int8 ONNX 已生成，static int8 ONNX 大小 301,677 bytes。

仍需要用户或 Android 端侧协作方提供：

- Android App 工程位置或接入队友。
- 可用于真机测速的目标 Android 设备型号。
- ONNX Runtime Android 版本锁定结果。
- 真机 p50/p90 延迟、内存、发热、连续相机预览稳定性测试结果。
