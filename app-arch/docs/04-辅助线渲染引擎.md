# 模块四：辅助线渲染引擎

> 这是 App 的核心视觉层。队友定义**画什么**，你负责**画出来**。
>
> ⚠️ 渲染框架不依赖队友（可先用硬编码数据画测试线），具体辅助线类型依赖队友的设计稿。

---

## 4.1 辅助线类型（预期）

队友的模型可能输出以下类型的辅助线（具体以队友的设计稿为准）：

| 类型 | 说明 | 渲染方式 |
|------|------|----------|
| 三分线网格 | 两条水平线 + 两条垂直线 | 细线 + 低透明度 |
| 三分点标记 | 四个交叉点的高亮标记 | 小圆点/十字准星 |
| 主体定位框 | 框出画面主体 | 圆角矩形描边 |
| 方向引导箭头 | 提示用户移动方向 | 动画箭头 |
| 目标区域高亮 | 建议主体放置的位置 | 半透明圆形/椭圆形区域 |
| 水平仪 | 显示画面倾斜角度 | 弧形刻度 + 指针 |
| 引导线 | 画面中的天然引导线方向 | 虚线/箭头线 |
| 构图框架 | 对称轴/黄金螺旋/三角构图线 | 对应几何图形 |

## 4.2 渲染方案

### 自定义 Overlay View

```kotlin
class CompositionOverlayView @JvmOverloads constructor(
    context: Context,
    attrs: AttributeSet? = null
) : View(context, attrs) {

    private var guideLines: List<GuideLine> = emptyList()

    // 动画状态
    private var pulseAlpha: Float = 1.0f
    private var flowOffset: Float = 0.0f

    private val paint = Paint().apply {
        isAntiAlias = true
        style = Paint.Style.STROKE
        strokeWidth = 2.dpToPx()
    }

    fun updateGuideLines(lines: List<GuideLine>) {
        guideLines = lines
        invalidate()  // 触发 onDraw
    }

    override fun onDraw(canvas: Canvas) {
        super.onDraw(canvas)
        for (line in guideLines) {
            drawGuideLine(canvas, line)
        }
    }

    private fun drawGuideLine(canvas: Canvas, line: GuideLine) {
        when (line.type) {
            GuideLineType.GRID -> drawGrid(canvas, line.params)
            GuideLineType.THIRDS_POINTS -> drawThirdsPoints(canvas, line.params)
            GuideLineType.SUBJECT_BOX -> drawSubjectBox(canvas, line.params)
            GuideLineType.ARROW -> drawArrow(canvas, line.params)
            GuideLineType.TARGET_ZONE -> drawTargetZone(canvas, line.params)
            GuideLineType.HORIZON_LEVEL -> drawHorizonLevel(canvas, line.params)
            GuideLineType.GUIDE_LINE -> drawGuideLinePath(canvas, line.params)
            GuideLineType.FRAMEWORK -> drawFramework(canvas, line.params)
            // 队友每次定义新类型，这里加一个 case
        }
    }
}
```

### 各类型渲染示例

```kotlin
/** 三分线网格 */
private fun drawGrid(canvas: Canvas, params: GridParams) {
    paint.style = Paint.Style.STROKE
    paint.strokeWidth = 1.dpToPx()
    paint.color = Color.argb(80, 255, 255, 255)  // 白色半透明

    val w = width.toFloat()
    val h = height.toFloat()

    for (vLine in params.verticalLines) {
        val x = vLine * w
        canvas.drawLine(x, 0f, x, h, paint)
    }
    for (hLine in params.horizontalLines) {
        val y = hLine * h
        canvas.drawLine(0f, y, w, y, paint)
    }
}

/** 主体定位框 */
private fun drawSubjectBox(canvas: Canvas, params: SubjectBoxParams) {
    paint.style = Paint.Style.STROKE
    paint.strokeWidth = 2.dpToPx()
    paint.color = Color.argb(200, 0, 200, 255)  // 青色

    val w = width.toFloat()
    val h = height.toFloat()
    val left = params.x * w
    val top = params.y * h
    val right = left + params.width * w
    val bottom = top + params.height * h

    // 圆角矩形框
    canvas.drawRoundRect(left, top, right, bottom, 8.dpToPx(), 8.dpToPx(), paint)

    // 四角加强标记
    val cornerLen = 12.dpToPx()
    paint.strokeWidth = 3.dpToPx()
    // 左上角
    canvas.drawLine(left, top, left + cornerLen, top, paint)
    canvas.drawLine(left, top, left, top + cornerLen, paint)
    // 其他三角类似 ...
}

/** 水平仪 */
private fun drawHorizonLevel(canvas: Canvas, params: HorizonParams) {
    val cx = width / 2f
    val cy = height * 0.85f
    val radius = 40.dpToPx()

    // 弧形背景
    paint.style = Paint.Style.STROKE
    paint.strokeWidth = 3.dpToPx()
    paint.color = Color.argb(100, 255, 255, 255)
    canvas.drawArc(cx - radius, cy - radius, cx + radius, cy + radius, -30f, 60f, false, paint)

    // 指针（根据 angle_degrees 偏转）
    val angle = params.angleDegrees
    paint.color = when {
        abs(angle) < 1.0f -> Color.GREEN
        abs(angle) < 3.0f -> Color.YELLOW
        else -> Color.RED
    }
    val rad = Math.toRadians(angle.toDouble())
    val pointerLen = radius * 0.8f
    canvas.drawLine(
        cx, cy,
        cx + pointerLen * sin(rad).toFloat(),
        cy - pointerLen * cos(rad).toFloat(),
        paint
    )
}
```

## 4.4 坐标映射

模型输出的坐标通常是归一化坐标（0.0–1.0），需要映射到 View 的实际像素：

```kotlin
/** 归一化坐标 → Overlay View 像素坐标 */
fun normalizeToView(modelX: Float, modelY: Float, viewWidth: Int, viewHeight: Int): PointF {
    return PointF(modelX * viewWidth, modelY * viewHeight)
}

/** 考虑前置摄像头镜像的坐标映射 */
fun normalizeToViewWithMirror(
    modelX: Float,
    modelY: Float,
    viewWidth: Int,
    viewHeight: Int,
    isFrontCamera: Boolean
): PointF {
    val x = if (isFrontCamera) (1.0f - modelX) * viewWidth else modelX * viewWidth
    return PointF(x, modelY * viewHeight)
}
```

## 4.5 动画驱动框架

```kotlin
// 脉冲动画（目标点呼吸效果）
private val pulseAnimator = ValueAnimator.ofFloat(0.5f, 1.0f).apply {
    duration = 1000
    repeatCount = ValueAnimator.INFINITE
    repeatMode = ValueAnimator.REVERSE
    addUpdateListener { animation ->
        pulseAlpha = animation.animatedValue as Float
        invalidate()
    }
}

// 流动动画（沿引导线的光点/虚线移动）
private val flowAnimator = ValueAnimator.ofFloat(0f, 1f).apply {
    duration = 1500
    repeatCount = ValueAnimator.INFINITE
    addUpdateListener { animation ->
        flowOffset = animation.animatedValue as Float
        invalidate()
    }
}

// 在 onAttachedToWindow / onDetachedFromWindow 管理动画生命周期
override fun onAttachedToWindow() {
    super.onAttachedToWindow()
    pulseAnimator.start()
    flowAnimator.start()
}

override fun onDetachedFromWindow() {
    super.onDetachedFromWindow()
    pulseAnimator.cancel()
    flowAnimator.cancel()
}
```

## 4.6 数据结构定义

> 以下是建议的数据结构。最终以队友的输出 schema 为准。

```kotlin
enum class GuideLineType {
    GRID,            // 三分线网格
    THIRDS_POINTS,   // 三分点
    SUBJECT_BOX,     // 主体框
    ARROW,           // 方向箭头
    TARGET_ZONE,     // 目标区域
    HORIZON_LEVEL,   // 水平仪
    GUIDE_LINE,      // 引导线
    FRAMEWORK        // 构图框架
}

sealed class GuideLineParams {
    data class GridParams(val verticalLines: FloatArray, val horizontalLines: FloatArray) : GuideLineParams()
    data class SubjectBoxParams(val x: Float, val y: Float, val width: Float, val height: Float) : GuideLineParams()
    data class TargetZoneParams(val centerX: Float, val centerY: Float, val radius: Float) : GuideLineParams()
    data class HorizonParams(val angleDegrees: Float) : GuideLineParams()
    data class ArrowParams(val fromX: Float, val fromY: Float, val toX: Float, val toY: Float) : GuideLineParams()
    data class GuideLinePathParams(val points: FloatArray) : GuideLineParams()  // [x0,y0, x1,y1, ...]
    data class FrameworkParams(val frameworkType: String, val points: FloatArray) : GuideLineParams()
}

data class GuideLine(
    val type: GuideLineType,
    val visible: Boolean,
    val params: GuideLineParams
)
```

## 4.7 验证标准

- [ ] 硬编码三分线 + 矩形框 + 圆圈正确显示在预览画面上
- [ ] 坐标映射正确（线/框的位置跟画面内容对齐）
- [ ] 前置摄像头 X 翻转正确
- [ ] 横竖屏旋转后坐标正确
- [ ] 动画流畅不卡预览（onDraw < 5ms）
- [ ] 频繁 invalidate 时无掉帧（用 Profiler 验证）
- [ ] 动画在前后台切换时正确暂停/恢复
