# 模块三：AI 模型接入

> 当前最新接入方案见 [09-AI接入包说明](./09-AI接入包说明.md)。v9 首发候选不是 `.tflite` 直出辅助线，而是 `ONNX static int8 -> 512 维 embedding -> 模板 top5 检索 -> 规则重排 -> metadata 转辅助线`。

---

## 3.1 模型做了什么

```text
相机画面
  -> v9 ONNX Runtime Mobile
  -> 512 维 L2 normalized embedding
  -> 模板索引 top8/top10 召回
  -> top5 + 规则重排
  -> 选中模板 metadata
  -> App 渲染辅助线/提示
```

注意：当前 v9 ONNX 只输出 embedding，不输出场景类别、构图策略或辅助线坐标。辅助线来自检索命中的模板 metadata，不是模型 tensor 直接吐出来的。

## 3.2 App 职责

1. 接收模型和索引文件：`student_model.static_int8.onnx` + `template_index/`。
2. 加载 ONNX Runtime session，App 启动时异步准备。
3. 预处理：RGB、224x224、NCHW、`(rgb/255 - 0.5) / 0.5`。
4. 执行推理：输出 512 维 embedding。
5. 检索索引：召回 top8/top10，显示前取 top5 重排。
6. 解析模板 metadata：映射成三分线、中心线、水平线、留白提示等。
7. 结果稳定：低 margin 时保持旧模板，避免频繁跳变。
8. 模型更新：模型、索引、metadata 必须同版本更新。

## 3.3 Android 推理方案选型

| 框架 | 适用场景 | 当前建议 |
|------|----------|----------|
| ONNX Runtime Mobile | 当前 v9 static int8 ONNX 包 | 首选 |
| TFLite / LiteRT | 后续如要 `.tflite` 商业包 | 需要重新导出和静态量化评估 |
| NCNN | 极致包体/CPU 优化 | 需要重新导出和 Android 集成评估 |
| MediaPipe / ML Kit | 辅助人脸、姿态、主体检测 | 可作为坐标检测补充 |

当前不要把 TorchScript dynamic int8 当 Android 商用量化包；它只量化 Linear 层，卷积仍是 FP32。

## 3.4 ONNX Runtime 集成

Gradle 依赖建议：

```kotlin
dependencies {
    implementation("com.microsoft.onnxruntime:onnxruntime-android:1.19.2")
}
```

模型加载伪代码：

```kotlin
class V9EmbeddingModel(modelPath: String) : Closeable {
    private val env = OrtEnvironment.getEnvironment()
    private val session = env.createSession(modelPath, OrtSession.SessionOptions().apply {
        setIntraOpNumThreads(2)
    })

    fun embed(nchw224: FloatArray): FloatArray {
        val shape = longArrayOf(1, 3, 224, 224)
        OnnxTensor.createTensor(env, FloatBuffer.wrap(nchw224), shape).use { tensor ->
            session.run(mapOf("image" to tensor)).use { result ->
                val embedding = (result[0].value as Array<FloatArray>)[0]
                return l2Normalize(embedding)
            }
        }
    }

    override fun close() {
        session.close()
    }
}
```

推理调用：

```kotlin
fun runRecommendation(bitmap: Bitmap, context: SceneContext): Recommendation {
    val input = bitmapToNchw224(bitmap)
    val embedding = model.embed(input)
    val hits = templateIndex.search(embedding, topK = 8)
    val ranked = reranker.rerank(hits, context).take(5)
    return stabilizer.stabilize(ranked)
}
```

## 3.5 结果稳定

top1/top2 margin 小于 0.01 时不要立刻切模板。建议新候选连续 2-3 次稳定领先后再切换，否则保持上一条稳定推荐。

```kotlin
class RecommendationStabilizer(
    private val lowMargin: Float = 0.01f,
    private val requiredStableSamples: Int = 2
) {
    private var current: Template? = null
    private var pending: Template? = null
    private var pendingCount = 0

    fun stabilize(top5: List<TemplateScore>): Recommendation {
        if (top5.isEmpty()) return Recommendation.Empty
        val best = top5[0]
        val second = top5.getOrNull(1)
        val margin = if (second == null) 1f else best.score - second.score
        if (current == null || margin >= lowMargin) {
            current = best.template
            pending = null
            pendingCount = 0
        } else if (best.template.id != current?.id) {
            pendingCount = if (pending?.id == best.template.id) pendingCount + 1 else 1
            pending = best.template
            if (pendingCount >= requiredStableSamples) current = best.template
        }
        return Recommendation(current!!, top5)
    }
}
```

## 3.6 不依赖 AI 侧的验证方式

在 Android 工程里先用任意本地 `.onnx` 或当前 `student_model.fp32.onnx` 跑通 ONNX Runtime 加载和输入输出 shape。拿到静态 int8 包后替换成 `student_model.static_int8.onnx`。

1. 模型能从 assets 或 app-private path 加载。
2. 输入 `[1,3,224,224]` float32。
3. 输出 `[1,512]` float32。
4. 输出 L2 norm 约等于 1。
5. 单帧耗时埋点能记录 p50 / p90。

## 3.7 验证标准

- [ ] `student_model.static_int8.onnx` 能加载无异常。
- [ ] `templates.metadata.jsonl`、`templates.embeddings.f32`、`templates.keys.json` 能加载无异常。
- [ ] 单帧 embedding 耗时达到 p50 <= 80ms、p90 <= 150ms。
- [ ] 相机预览按 500ms-1000ms 或画面变化触发，不每帧推理。
- [ ] 推荐结果使用 top5 + 规则重排。
- [ ] 连续推理 10 分钟内存稳定。
- [ ] 低 margin 场景下辅助线无明显抖动。
- [ ] 前后摄切换后推理继续正常。
