## 1.1 技术选型

| 事项 | 方案 | 备注 |
|------|------|------|
| **框架** | CameraX | Google 官方推荐，封装 Camera2 复杂性 |
| **最低 API** | 24 (Android 7.0) | CameraX 兼容性良好 |
| **预览** | `PreviewView` | 支持缩放/裁剪模式切换 |
| **拍照** | `ImageCapture` | 支持单拍 + 连拍 |
| **帧分析** | `ImageAnalysis` | 用于 AI 推理，配置 `OUTPUT_IMAGE_FORMAT_YUV_420_888` |
| **语言** | Kotlin | 现代 Android 开发标准 |

## 1.3 CameraX 初始化

```kotlin
// 核心配置示例
val imageAnalysis = ImageAnalysis.Builder()
    .setBackpressureStrategy(ImageAnalysis.STRATEGY_KEEP_ONLY_LATEST) // ★ 关键：只保留最新帧
    .setOutputImageFormat(ImageAnalysis.OUTPUT_IMAGE_FORMAT_YUV_420_888)
    .setTargetResolution(android.util.Size(640, 480))  // 推理不需要全分辨率
    .build()

val cameraProviderFuture = ProcessCameraProvider.getInstance(context)
cameraProviderFuture.addListener({
    val cameraProvider = cameraProviderFuture.get()
    val preview = Preview.Builder().build().also {
        it.setSurfaceProvider(previewView.surfaceProvider)
    }
    val imageCapture = ImageCapture.Builder()
        .setCaptureMode(ImageCapture.CAPTURE_MODE_MAXIMIZE_QUALITY)
        .build()

    // 绑定到生命周期
    val camera = cameraProvider.bindToLifecycle(
        lifecycleOwner,
        CameraSelector.DEFAULT_BACK_CAMERA,
        preview,
        imageCapture,
        imageAnalysis
    )
}, ContextCompat.getMainExecutor(context))
```

## 1.4 拍照与保存

```kotlin
// 拍照 → 保存到 MediaStore
imageCapture.takePicture(
    ContextCompat.getMainExecutor(context),
    object : ImageCapture.OnImageSavedCallback {
        override fun onImageSaved(output: ImageCapture.OutputFileResults) {
            // 通知相册刷新
            val savedUri = output.savedUri
            // 可发广播或直接通过 URI 访问
        }
        override fun onError(exception: ImageCaptureException) {
            // 错误处理（对焦失败、存储空间不足等）
            Log.e("Camera", "Capture failed", exception)
        }
    }
)
```

**拍照需提前配置输出目标**：

```kotlin
val imageCapture = ImageCapture.Builder()
    .setCaptureMode(ImageCapture.CAPTURE_MODE_MAXIMIZE_QUALITY)
    .build()

// 构建时指定保存位置
val outputOptions = ImageCapture.OutputFileOptions.Builder(
    contentResolver,
    MediaStore.Images.Media.EXTERNAL_CONTENT_URI,
    contentValues
).build()

imageCapture.takePicture(
    outputOptions,
    executor,
    callback
)
```

## 1.5 关键注意事项

| 问题 | 处理 |
|------|------|
| 预览坐标 ≠ 照片坐标 | 拍照用全分辨率，预览是裁剪后的。辅助线坐标必须基于预览坐标系 |
| 前置摄像头镜像 | 预览时 CameraX 自动镜像，但 `ImageAnalysis` 的帧**不自动镜像**——如果你用分析帧画辅助线，需要手动翻转 X 坐标 |
| 旋转角度 | `imageProxy.imageInfo.rotationDegrees` 获取当前帧的旋转角度，用于坐标变换 |
| 权限流程 | 检查 → 请求 → 拒绝时引导去设置页 |
| 生命周期 | 相机绑定到 `ViewLifecycleOwner`（Fragment）或 `LifecycleOwner`（Activity） |
