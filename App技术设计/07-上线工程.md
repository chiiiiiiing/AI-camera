# 模块七：上线工程

> 把代码变成用户手机上的 App。**不依赖队友，建议项目初期就搭好骨架。**

---

## 7.1 工程搭建

| 事项 | 推荐方案 |
|------|----------|
| 构建系统 | Gradle (Kotlin DSL) |
| 架构 | MVVM（ViewModel + StateFlow） |
| UI 框架 | View 体系（`CompositionOverlayView` 用自定义 View）或 Jetpack Compose |
| DI | Hilt（推荐）或手动 DI |
| 图片加载 | Coil |
| 网络（如有） | OkHttp + Retrofit |
| 数据持久化 | Room（如需本地缓存设置/历史） |
| 崩溃监控 | Firebase Crashlytics 或 Bugly |

### 包结构建议

```

├── camera/              # 相机链路
```

## 7.4 模型下发方案

如果 AI 侧后续要更新模型，你需要支持“模型 + 索引 + metadata”同版本下发：

### 方案 A：打包在 APK 内（MVP 推荐）

- ✅ 优点：简单，首次即用，无网络依赖
- 缺点：更新模型需发版

### 方案 B：Firebase Remote Config + 远程下载（V1.1+）

- 优点：模型可独立于 App 版本更新
- 缺点：需要网络、下载逻辑、本地缓存、版本管理

```
MVP 阶段：方案 A（模型放 assets/）
稳定后：方案 B（支持热更新模型）
```

### 方案 B 实现要点

```kotlin
class ModelDownloader(private val context: Context) {
    private val modelDir = context.filesDir.resolve("models")

    fun checkAndDownload(targetVersion: Int) {
        val currentVersion = getCurrentModelVersion()
        if (currentVersion >= targetVersion) return

        // 下载新模型包：ONNX + runtime config + template_index
        val url = "https://your-cdn.com/models/v${targetVersion}/ai_v9_bundle.zip"
        // OkHttp 下载 -> 校验 sha256 -> 解压到 modelDir/vN.tmp -> 原子切换 current
    }

    private fun getCurrentModelVersion(): Int {
        return context.getSharedPreferences("model", Context.MODE_PRIVATE)
            .getInt("version", 0)
    }
}
```
