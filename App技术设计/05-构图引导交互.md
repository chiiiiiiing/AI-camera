## 5.2 辅助线动画思路

队友要求"生动的辅助线"，大概率不会只是静态线条：

```kotlin
// 脉冲动画示例（目标点呼吸效果）
val pulseAnimator = ValueAnimator.ofFloat(0.5f, 1.0f).apply {
    duration = 1000
    repeatCount = ValueAnimator.INFINITE
    repeatMode = ValueAnimator.REVERSE
    addUpdateListener { animation ->
        pulseAlpha = animation.animatedValue as Float
        invalidate()  // 重绘
    }
    start()
}

// 箭头流动动画（沿引导线方向移动的虚线/光点）
val arrowFlowAnimator = ValueAnimator.ofFloat(0f, 1f).apply {
    duration = 1500
    repeatCount = ValueAnimator.INFINITE
    addUpdateListener { animation ->
        flowOffset = animation.animatedValue as Float
        invalidate()
    }
    start()
}
```

### 动画管理

```kotlin
// 在 View 的生命周期回调里管理动画
override fun onAttachedToWindow() {
    super.onAttachedToWindow()
    startAllAnimations()
}

override fun onDetachedFromWindow() {
    super.onDetachedFromWindow()
    cancelAllAnimations()
}
```

## 5.3 构图达标反馈

```kotlin
class CompositionFeedback(
    private val view: View,
    private val vibrator: Vibrator?
) {
    private var wasGoodComposition = false

    fun onCompositionResult(quality: CompositionQuality) {
        when {
            quality.isGood && !wasGoodComposition -> {
                // 刚达标：震动 + 视觉反馈
                vibrator?.hapticFeedback(HapticFeedbackConstants.CONTEXT_CLICK)
                view.showGoodCompositionIndicator()  // 绿色边框闪烁等
            }
            !quality.isGood && wasGoodComposition -> {
                // 刚失去达标状态
                view.hideGoodCompositionIndicator()
            }
        }
        wasGoodComposition = quality.isGood
    }
}
```

## 5.4 提示文案显示

```kotlin
// 底部提示条，队友提供文案
class HintOverlay(context: Context) : TextView(context) {
    private val fadeAnimator = ValueAnimator.ofFloat(1f, 0f).apply {
        duration = 300
        startDelay = 2000  // 显示 2 秒后渐隐
        addUpdateListener { alpha = animatedValue as Float }
    }

    fun showHint(text: String) {
        this.text = text
        alpha = 1f
        fadeAnimator.cancel()
        fadeAnimator.start()
    }
}
```

## 5.5 状态机设计

```
[未识别主体] ──检测到主体──▶ [已识别主体]
                                  │
                         用户调整构图
                                  │
                                  ▼
                            [正在调整]
                                  │
                         构图达标 (连续N帧)
                                  │
                                  ▼
                            [构图较好]
                                  │
                         用户可拍摄 / 提示
                                  │
                                  ▼
                            [已拍摄]
```

```kotlin
enum class CompositionState {
    NO_SUBJECT,       // 未识别主体
    SUBJECT_FOUND,    // 已识别主体
    ADJUSTING,        // 正在调整
    GOOD_COMPOSITION, // 构图较好
    CAPTURED          // 已拍摄
}

class CompositionStateMachine {
    private var currentState = CompositionState.NO_SUBJECT
    private var goodFrameCount = 0
    private val GOOD_THRESHOLD = 5  // 连续 5 帧才算达标

    fun update(quality: CompositionQuality): CompositionState {
        val nextState = when (currentState) {
            CompositionState.NO_SUBJECT ->
                if (quality.hasSubject) CompositionState.SUBJECT_FOUND
                else CompositionState.NO_SUBJECT

            CompositionState.SUBJECT_FOUND ->
                if (!quality.hasSubject) CompositionState.NO_SUBJECT
                else if (quality.isGood) {
                    goodFrameCount++
                    if (goodFrameCount >= GOOD_THRESHOLD) CompositionState.GOOD_COMPOSITION
                    else CompositionState.SUBJECT_FOUND
                } else {
                    goodFrameCount = 0
                    CompositionState.ADJUSTING
                }

            CompositionState.ADJUSTING ->
                if (!quality.hasSubject) CompositionState.NO_SUBJECT
                else if (quality.isGood) {
                    goodFrameCount++
                    if (goodFrameCount >= GOOD_THRESHOLD) CompositionState.GOOD_COMPOSITION
                    else CompositionState.ADJUSTING
                } else {
                    goodFrameCount = 0
                    CompositionState.ADJUSTING
                }

            CompositionState.GOOD_COMPOSITION ->
                if (!quality.hasSubject) CompositionState.NO_SUBJECT
                else if (!quality.isGood && goodFrameCount < GOOD_THRESHOLD) CompositionState.ADJUSTING
                else CompositionState.GOOD_COMPOSITION

            CompositionState.CAPTURED -> CompositionState.NO_SUBJECT
        }

        currentState = nextState
        return nextState
    }
}
```

## 5.6 你不应该花时间的地方

- 辅助线的颜色、粗细、透明度 → **队友定**
- 按钮位置、大小、图标 → **队友出设计稿**
- 动画节奏 → **队友给参考**
- 提示文案 → **队友写**

你的重点是：**渲染性能**（不掉帧）、**坐标正确**（不偏移）、**状态同步**（不抖动）。
