# GenWow 人物姿势引导 v7：以视觉优化稿为造型基准

## 这次真正修改的内容

- **不再继承 v6 的人物轮廓**。以用户 2026-10-16 上传的六状态视觉稿中第 5 个站姿人物为造型参考，重新绘制长发、宽松上衣、自然弯曲的抬臂、宽腿裤和鞋。
- 采用单条连续闭合 `path` 表达人物外边界，肩、肘、手掌不再作为独立贴片覆盖在身体上。
- 统一人物画布与躯干、右臂、双腿路径，四个状态仅修改左臂区域；以防不同状态身高、腿长和腰线跳动。
- 视觉稿是位图，v7 是**人工参考重绘**，不是逐像素矢量化；不能承诺完全一致。需要设计同学在 Figma/Illustrator 中对照进一步微调。

## 文件说明

- `svg/components/figure_{down,low,mid,up}.svg`：四种可编辑的单路径人体轮廓，目标人物造型与原稿接近。
- `svg/components/correction_*.svg`：独立粉色局部纠错弧线样式，**不代表算法已经给出真实方向**。
- `svg/states/pose_*.svg`：8 种展示状态，分组 ID `target-outline` / `current-outline` / `correction-arc` / `garment-details`。
- `preview/pose_state_board_v7.png`：评审板，英文仅用于评审；运行时 SVG 没有动作提示文字。
- `preview/reference_proportions_v7.png`：四姿势的同尺度比例比较。
- `fixtures/pose_mock.json`：模拟联调数据，不含真实姿态检测结果。

## APP 动态接入边界

1. 当前 GenWow AI 文档仅明确人脸/对象构图引导，并未交付可用的完整人体关键点、人体分割、姿势误差与姿势验证接口。
2. **当前人物轮廓必须从真实人体分割或可信的参数化模型得到**。本包固定轮廓是设计模板，不能宣称它与真人边缘实时贴合。
3. 动态运行时，保持目标姿势与当前姿势在同一显示坐标空间；前摄已经镜像的坐标不得重复翻转。
4. 粉色弧线应由有效肩/肘/腕关键点和经过验证的关节运动方向决定；置信度不足时隐藏，不按时间自动推进。
5. `VERIFYING` 仍使用白色；绿色 `ALIGNED` 必须由未来独立的姿势验证器输出，不复用当前构图 Ready。
6. 建议 Compose Canvas 绘制参数化连续轮廓；静态 SVG 可以用于目标模板、设计基准、回退示意，但不能通过直接插值这些 SVG 路径宣称已完成实时人体追踪。
7. 原 `AI-camera` 仓库未修改。

## 验收重点

- 设计：头发自然、肩肘腕连续、宽松上衣与宽腿裤比例稳定；四姿势的非运动部位完全一致。
- 动态：目标切换、丢帧、换人、镜头切换时立即撤销旧纠错；不让动画自己触发姿势完成。
- **限制**：仍需人工视觉复核，缺少真实人体姿态 AI、动态外轮廓变形、真机验证。
