# UI 设计交付清单

核对日期：2026-10-16。本清单用于非引导部分的视觉协作；具体页面现状以 Android 源码为准，Web 预览不是运行能力证明。旧版“根据 Figma 推断已实现”的勾选表已移除。

**摄影引导统一阅读[引导动画制作与接入规范](./引导动画制作与接入规范.md)**，其中包含动作、反馈、分镜、颜色、素材格式及待接线项，不另维护一套五类动画清单。

## 页面交付范围

下表是交付内容要求，不表示这些页面仍未实现，也不表示设计已经验收。

| 范围 | 设计交付 |
|---|---|
| 相机控件 | 快门、切摄像头、闪光灯、变焦、对焦曝光、滤镜和 Pro 控件；正常、按下、禁用及加载态 |
| 拍后结果／相册 | 真实保存成功、保存失败、图片加载失败、返回及重拍；不加入无依据的构图分数 |
| 社区／个人页 | 卡片、互动选中态、作品网格、头像占位、空白／错误态；本地演示数据不写成云端成功 |
| 登录／注册 | 表单、校验、加载、失败、返回及可访问性；未接入服务不伪装成成功授权 |
| 设置 | 开关、滑条、分组、默认值、禁用态与说明；已有引导显示设置须有效 |
| 品牌／启动 | 图标、启动页、品牌字样；启动器提供自适应图标前景／背景和预览 |

## 交付格式

| 内容 | 格式 |
|---|---|
| 可编辑设计稿 | 本地源文件＋可选设计链接，注明页面／组件版本 |
| 图标 | SVG 源文件、透明 PNG 回退、逻辑尺寸及导出倍率；Android 接入需转 VectorDrawable 或 Canvas |
| 图片 | PNG 或适用的压缩图片，标明裁切方式及来源 |
| 视觉参数 | 颜色、字号、字重、间距、圆角、触控区域、安全区和各状态说明 |
| 动效 | 可编辑源、时序说明、MP4 预览及静态帧；Lottie/Rive 不是当前已接入运行时 |
| 验收对照 | 各关键状态截图及已知差异，不以一张理想页面代替异常态 |

文字保留为 App 文本，不烘焙进图片。布局需适应字体放大、不同屏幕宽度、系统栏和横竖画幅。图标与文字一起表达状态，不只靠颜色。设计预览不拦截快门、返回或取消等关键操作。

实际页面、引导模型能力和设计愿景分开标注。涉及动作／Ready 的变更先更新引导规范和状态适配，再制作效果，避免同一状态在两个交付清单里含义不同。
