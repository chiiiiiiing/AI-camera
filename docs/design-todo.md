# UI / 设计侧待办清单

更新日期：2026-07-21

这个文件只记录仍需要由 UI/设计负责人在 Figma 或设计交付层继续完成、确认或拍板的事项。

## 1. Figma 最终定稿

- 确认相机页当前快门、引导提示条、变焦条是否作为最终视觉版本
- 确认社区卡片当前圆角、图片占比、互动区留白是否作为最终版本
- 确认个人主页、编辑资料页、设置页当前布局是否进入最终设计稿

## 2. 品牌与资源交付

- 输出正式 App 图标设计包
  - mdpi / hdpi / xhdpi / xxhdpi / xxxhdpi PNG
  - 品牌原始矢量源文件
- 如需对外设计交付，整理当前使用 icon 的统一设计源稿

## 3. 动效签版

- 确认以下状态是否沿用当前实现节奏：
  - 平移引导
  - 轴旋转引导
  - 面内旋转引导
  - WRONG_DIRECTION
  - NEAR
  - ALIGNED
- 如团队需要正式设计交付件，补充 GIF / MP4 / Lottie 参考

## 4. 视觉令牌签版

- 最终确认品牌色、引导色、完成色、警示色
- 最终确认文字层级、圆角、透明度、间距标注
- 在 Figma 中沉淀最终标注，供后续开发和验收对照

## 5. 可选的后续设计扩展

- 是否为社区页补充评论详情页设计
- 是否为设置页补充更完整的账号与隐私配置设计
- 是否为编辑资料页补充头像裁切 / 更换封面等扩展流程
