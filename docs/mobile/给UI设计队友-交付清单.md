### 2.2 引导动画 — 5 种视觉状态

**已实现**（根据 Figma + 设计规范推断）：

| 状态 | 视觉效果 | 当前实现 |
|------|----------|----------|
| NONE（无引导） | 低透明度目标框 + 呼吸 | ✅ Compose Canvas |
| TRANSLATION（平移） | 目标太阳 + 十字准心 + 移动箭头 | ✅ 完整实现 |
| AXIS_ROTATION（轴旋转） | 渐隐轴线 + 透视椭圆弧 + 箭头 | ✅ 完整实现 |
| PLANAR_ROTATION（面内旋转） | 手机外框 + 旋转轨道弧 + 箭头 | ✅ 完整实现 |
| SUBJECT（主体轮廓） | 虚线轮廓 + 锚点 | ✅ 绘制代码就绪 |

**需要你交付的**：
- [ ] **每种引导状态的动画视频/GIF 参考**（最关键！）。代码目前按设计规范推导了动画节奏，但需要你确认：
  - 平移箭头的摆动幅度和速度是否 OK？
  - 透视弧的流动速度是否 OK？
  - 对齐后的完成动画（checkmark + 收束）的节奏？
- [ ] **WRONG_DIRECTION（方向错误）状态的视觉**：目前用橙色 + 反向箭头。需要你确认颜色和动画效果
- [ ] **NEAR（接近目标）vs ADJUST（远离目标）** 的视觉差异：目前 NEAR 时摆动幅度减半，正确吗？
- [ ] 引导线的颜色确认：目前用的是青色 `#35C6D4`（正常）、绿色 `#8CE0C3`（对齐）、橙色 `#FF9D55`（警告）。需要你确认/修改

## 4. 资源交付格式

| 类型 | 格式 | 说明 |
|------|------|------|
| 图标 | SVG 优先 → PNG 备选 | SVG 可通过 Vector Asset 导入 Android |
| 图片素材 | PNG (1x/2x/3x) | 或单一高分辨率由开发侧缩放 |
| 动画参考 | MP4 / GIF / Lottie JSON | 手机录屏最好 |
| 颜色/字体/间距 | Figma 标注链接 或 手写文档 | 不用导出，给 Figma 链接 + 对应 node 即可 |

## 5. FAQ

**Q: Figma 链接就够了，为什么还要列清单？**
A: Figma 是设计源文件，这个清单是"哪些东西已经被实现了、哪些还需要"的对照表。可以避免你花时间设计已经落地的东西。

**Q: 辅助线的颜色我还没定？**
A: 那就按当前代码里的值先用。你定稿后我批量替换颜色令牌即可，改起来很快。

**Q: 我可以直接在 Figma 里改吗？**
A: 可以。改完后告诉我哪些 node 更新了，我去重新导出。

**Q: 需要做 iOS 版的设计吗？**
A: 不需要。V2.0 之前只有 Android。
