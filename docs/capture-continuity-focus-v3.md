# 连续引导与点击对焦修复

日期：2026-10-20。

## 原因

- 物体检测间隔 600ms，V9 一次超过 150ms 即退避到 800ms，持续十秒，实际更新频率经常约一秒一次。
- 同一物体原先要求重叠率至少 0.5、中心变化小于 0.15、外观签名严格一致。正常取景移动就可能重建 trackingId、清空稳定样本；单次漏检会清空主体。
- 场景检索类别一抖动就清空物体追踪状态。
- 主体短暂丢失后没有专门的视觉恢复状态，目标与方向一起消失。
- 对焦叠加层保留了曝光条，但没有绘制对焦框；手势未明确消费 onDown，单击等待双击确认，重复点击同一位置也没有重启显示计时。

## 修改

- V9 正常采样间隔 200ms，慢设备退避 500ms；退避由一次超过 350ms 触发，保持两秒。物体检测最短间隔 200ms，人脸检测最短间隔 120ms。这是调度目标，不能保证真机达到相应帧率。
- 物体关联优先匹配原主体，支持取景移动后的较低重叠率和合理尺寸变化。短暂漏检不会切换到另一个类别的显眼物体。
- 场景类别连续三次一致才切换；非人像类别间切换保留物体上下文。
- 新增 SubjectContinuity，短暂丢失时保留约 1200ms 的目标与最后实际观测；保留原采样 ID 和时间，不制造新检测。
- 恢复期间保持 Adjusting 与目标画面，撤销 Ready 和自动拍摄许可。恢复超时、换视口、出现多人时停止沿用旧观测。
- 自动对焦等待完成后重新检查 Ready 证据，避免主体已丢失却按旧 Ready 拍摄。手动快门不受此自动拍摄检查限制。
- 目标重新规划时生成新的计划 ID，控制器同步更新目标，避免界面画新点、判定还追旧点。
- 引导主体中心用 100ms 动画过渡，人脸位置平滑更快跟随实际移动。
- 恢复 56dp 对焦框；点击松开立即发送对焦事件；多指缩放不会在结束时误触发单击。重复点击同一位置也会重新显示，三秒无操作后隐藏。
