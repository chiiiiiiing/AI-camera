# GenWow 产品 Demo 拍摄方案

用约 90 秒展示「识别画面 → 单步引导 → 执行反馈 → 连续验证 → 拍摄保存」。这是一份录制计划，不表示真机或审美效果已验收。

## 准备

使用已完成基础相机检查的设备，关闭通知，使用自己的测试照片和测试账号。准备单人清晰人脸、稳定光线和一个便于小幅调整的场景。录制 App 实际操作，保留失败回退，不用剪辑把等待阶段伪装成模型成功。

## 分镜

| 时间 | 内容 | 说明 |
|---|---|---|
| 0–10s | 正常预览与手动对焦曝光 | 展示真实画面，不以网页模拟充当 App |
| 10–25s | 开始分析，出现端平或取景指令 | 只演示实际返回的一条动作，不预设模型一定会选中某目标 |
| 25–40s | 按指令小幅调整 | 区分手机动作与主体在画面中的位移 |
| 40–55s | 位置合适后保持验证 | 等控制器 Ready；当前局部变绿不单独作为达标证据 |
| 55–65s | Ready、拍摄准备、保存 | 说明自动拍摄前仍会重查依据；保存成功才展示完成勾 |
| 65–80s | 主体离开或画面明显变化 | 展示停止旧建议、重新确认或手动拍摄回退 |
| 80–90s | 结果与能力边界 | 展示保存照片；说明离线辅助及仍待验证的审美效果 |

可追加滤镜、Pro、社区及个人页演示，但注明手动操作、本地数据和设备支持范围。食物／静物演示需先确认获得了有效对象目标；不能仅因存在检测框就声称能指导取景。

## 展示边界

- 不展示不存在的美感分数、自动摆姿、完整人体轮廓或可靠语义地平线。
- 不把未接入的 Pitch/Yaw 目标和自动变焦写成当前摄影引导功能。
- 拍摄前后对照使用同一真实场景和清楚的操作记录，不把 AI 修复素材当实拍提升证据。
- 主体丢失、无可靠目标或推理失败时，可以展示保持与手动拍摄；不需要强行录出成功。
- 动画状态、当前接线缺口与文案以[引导动画制作与接入规范](./引导动画制作与接入规范.md)为准。
