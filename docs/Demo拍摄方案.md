# GenWow 产品 Demo 拍摄方案

目标：用 90–120 秒展示“相机理解画面 → 引导构图 → 拍摄保存 → 社区分享”的完整闭环。Demo 只展示当前已实现、可稳定复现的能力，不把人体分割、云端同步或 AI 自动滤镜说成已完成能力。

## 拍摄准备

- 使用已验证的 Android 真机，关闭通知和自动锁屏，清空相册中的无关内容。
- 预先授予相机和存储权限，准备一位人物、稳定光线和一张有明显构图主体的桌面场景。
- 准备一张社区示例图和一个“雨后电影感”滤镜资源。
- 录制竖屏 1080×1920；操作画面用屏幕录制，真实效果用第二台手机拍摄屏幕或录制后的样片补镜头。

## 分镜脚本

| 时间 | 画面 | 操作/旁白 |
|---|---|---|
| 0–6s | Logo 启动页进入相机 | “这是 GenWow，一台会用构图语言提示你的相机。” |
| 6–20s | 人像取景，出现主体框、目标点和方向箭头 | 缓慢向箭头方向移动手机，展示平移和水平引导；旁白说明辅助线是实时提示。 |
| 20–30s | 对齐后出现绿色状态、快门可拍 | “当画面稳定并达到当前构图目标，界面会明确提示可以拍摄。” |
| 30–42s | 点击屏幕对焦，出现对焦框和曝光条 | 拖动曝光条，展示画面变亮/变暗；点击快门拍摄。 |
| 42–55s | 拍摄结果、构图评分/保存反馈 | 展示照片保存和拍后反馈，不切换过多页面。 |
| 55–70s | 点击滤镜胶囊，展开封面列表 | 依次点选“奶油人像”和“日落胶片”，展示封面预览；强调滤镜由用户主动选择。 |
| 70–82s | 打开自定义滤镜编辑器 | 调整曝光、对比度、饱和度、色温和 RGB，保存为“我的人像”。 |
| 82–95s | 打开 Pro 模式 | 展示透明参数栏，依次点开 ISO、快门、白平衡和变焦；确保取景画面始终可见。 |
| 95–110s | 进入社区，打开示例作品 | 点赞、收藏、评论，并展示评论中的滤镜资源卡。 |
| 110–120s | 一键导入滤镜，进入个人主页 | “社区里的滤镜参数可以直接带回相机，作品、互动和资源形成闭环。” |

## 拍摄注意

- 不要用极暗、逆光、多人或快速移动场景做主 Demo，这些会放大模型和传感器误差。
- 录制自动变焦时，先展示主体明确、背景干净的人像；避免用数字裁切明显的超近距离场景。
- Pro 模式只展示参数控制，不声称所有手机都支持完整 ISO/快门/对焦范围。
- 备用镜头准备“AI 暂不可用/演示模式”安全降级画面，避免现场等待模型加载。
