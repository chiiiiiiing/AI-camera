# 仓库与本地目录说明

## 当前源码树

```text
AI-camera/
├── aicamera-app/      Android 主工程（唯一运行入口）
├── ai/
│   ├── tools/        模型/数据处理与校验源码、配置、测试
│   └── engine/       独立 C++ 引擎原型与测试
├── docs/             设计、接口、交付和验收文档
├── designs/          当前已纳入版本管理的设计资料
├── ui-review/        Web 预览工程
├── local-data/       本机私有数据与历史归档（Git 忽略）
├── local-output/     本机模型实验、缓存与验证结果（Git 忽略）
└── .github/workflows/ 自动验证和现有预览发布流程
```

`pack.sh`、`vercel.json` 为既有工程工具配置。`aicamera-app/server/` 保留既有认证服务代码，本轮未改其业务。

## 文件归属

| 内容 | 存放位置 | 是否提交 Git |
|---|---|---|
| 手机实际使用的 V9 模型、模板索引与配置 | `aicamera-app/app/src/main/assets/ai/v9/` | 是，作为同一交付包校验 |
| 模型处理、训练、量化和评估的代码 | `ai/tools/` | 是 |
| 训练照片、原始标注、teacher checkpoint、私人素材 | 项目内 `local-data/` | 否 |
| 重建的中间模型、embedding 缓存、实验结果 | 项目内 `local-output/` | 否；评审通过后才更新正式包 |
| 编译结果、临时回归 harness | 项目内 `build/` 或 `local-output/` | 否 |
| SDK 路径、IDE 缓存与本机配置 | 工程对应本地配置文件 | 否 |
| 历史已提交代码 | Git 历史 | 不重复复制到源码树 |

不要用全局 `*.onnx` 忽略规则隐藏正式 App 模型；本仓库仅按本地数据/输出目录隔离实验资产。

## 本机整理方式

本地文件统一保留在原 `AI-camera/` 项目目录内。2026-10-14 已将原同级归档整体迁至 `local-data/AI-camera-local-archive/2026-10-10/`，其中保存历史残留、原有未提交素材和验证产物。归档内 `整理清单.md` 与历史 manifest 保留整理发生时的原路径和哈希；查找归档文件时，将旧的同级 `AI-camera-local-archive/` 前缀替换为项目内的 `local-data/AI-camera-local-archive/`。归档文件内容不因迁移而改写，本地私有素材不推送 GitHub。

原工作目录 `AI-camera/` 最终切到此次发布分支，与 GitHub 使用相同的根目录布局。Git 保留原分支与提交，未提交文件通过本地归档保存。恢复某个旧文件时，先查看清单，再只复制所需内容到相应新目录，避免整套覆盖当前工程。

历史模型工具的 `check_pipeline.py` / `dataset_status.py` 可用 `--root` 指向 `local-data/AI-camera-local-archive/2026-10-10/private-data/`，该目录包含 `tools/raw_photos/`、`tools/preprocessed/`。搬迁素材不会自动改写归档标注中的绝对路径，重新训练前需检查路径。其他脚本请显式指定输入、输出和模型路径，避免依赖旧电脑目录。

本轮小模型实验位于 `local-output/model-optimization-2026-10-14/`。其中 `dataset/` 的图片和教师向量路径已迁移至当前归档位置，`audit.json` 记录当前清单哈希。`candidate-a/`、`candidate-b/` 的既有结果保留训练发生时的来源路径和清单哈希；各自的 `path-migration.json` 以及实验根目录下 `path-migration-2026-10-14/README.md` 说明新旧对应关系，并保留迁移前清单原文。路径迁移不改变样本划分或训练结果。

当前数据没有人工构图标注；历史 `composition`、`lighting`、`camera` 等字段主要来自规则推断，不应作为人工构图监督或独立构图准确率的依据。

最新识别模型、冻结测试、原正式模型备份与 406 条参考库构建记录位于 `local-output/model-recognition-2026-10-15/`。手机实际使用的模型仍统一放在 `aicamera-app/app/src/main/assets/ai/v9/`，该路径保留接口兼容；文件已改为通用 `student_model.onnx`，具体架构/精度以 manifest 为准。
