# 仓库与本地目录说明

## 当前源码树

```text
AI-camera/
├── aicamera-app/      Android 主工程（唯一运行入口）
├── ai/
│   ├── tools/        模型/数据处理与校验源码、配置、测试
│   └── engine/       独立 C++ 引擎原型与测试
├── docs/             设计、接口、交付和验收文档
├── designs/          当前已纳入版本管理的设计资料
├── ui-review/        Web 预览工程
└── .github/workflows/ 自动验证和现有预览发布流程
```

`pack.sh`、`vercel.json` 为既有工程工具配置。`aicamera-app/server/` 保留既有认证服务代码，本轮未改其业务。

## 文件归属

| 内容 | 存放位置 | 是否提交 Git |
|---|---|---|
| 手机实际使用的 V9 模型、模板索引与配置 | `aicamera-app/app/src/main/assets/ai/v9/` | 是，作为同一交付包校验 |
| 模型处理、训练、量化和评估的代码 | `ai/tools/` | 是 |
| 训练照片、原始标注、teacher checkpoint、私人素材 | 仓库外数据目录；临时也可用 `local-data/` | 否 |
| 重建的中间模型、embedding 缓存、实验结果 | 仓库外实验目录；临时也可用 `local-output/` | 否；评审通过后才更新正式包 |
| 编译结果、临时回归 harness | `build/` 或系统临时目录 | 否 |
| SDK 路径、IDE 缓存与本机配置 | 工程对应本地配置文件 | 否 |
| 历史已提交代码 | Git 历史 | 不重复复制到源码树 |

不要用全局 `*.onnx` 忽略规则隐藏正式 App 模型；本仓库仅按本地数据/输出目录隔离实验资产。

## 本机整理方式

本次在原工作目录的同级 `AI-camera-local-archive/2026-10-10/` 保存本地历史残留、原有未提交素材和验证产物，并生成 `整理清单.md`。清单记录原路径、归档路径、文件数与体积；本地私有素材不推送 GitHub。

原工作目录 `AI-camera/` 最终切到此次发布分支，与 GitHub 使用相同的根目录布局。Git 保留原分支与提交，未提交文件通过本地归档保存。恢复某个旧文件时，先查看清单，再只复制所需内容到相应新目录，避免整套覆盖当前工程。

历史模型工具的 `check_pipeline.py` / `dataset_status.py` 可用 `--root` 指向包含 `tools/raw_photos/`、`tools/preprocessed/` 的本地数据根目录；搬迁素材不会自动改写已有标注中的绝对路径，重新训练前需检查路径。其他脚本请显式指定输入、输出和模型路径，避免依赖旧电脑目录。
