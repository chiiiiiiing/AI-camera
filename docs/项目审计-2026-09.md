# 项目审计（2026-09）

本文用于核对外部审查截图中的判断，只记录当前仓库源码和构建结果能证明的事实。

## 结论

| 外部判断 | 核验结论 | 当前口径 |
|---|---|---|
| 真机 p50/p90、10–30 分钟稳定性未完成 | **属实** | 目前只有目标值和 JVM 单测，尚未在目标手机上完成延迟、内存、发热、前后台和前后摄切换验收。 |
| 人体姿态轮廓没有接入真实 AI | **基本属实** | 当前接入的是 ML Kit 人脸框；`RenderViewModel` 的 `subjectOutline` 仍为 `null`。姿态/轮廓素材不能等同于真实分割模型。 |
| 项目只有人脸框、没有通用主体分割 | **基本属实** | 当前可可靠演示的是人像矩形主体框；不能宣称已经支持精确人体轮廓、宠物/物体分割。 |
| 认证是后端真实能力 | **不属实** | 当前是本地 Room/演示后端链路；固定验证码仅用于 MVP 联调，不能用于正式上线。 |
| 社区是纯占位、没有 Repository | **不属实** | 已有 Room entities、DAO、`CommunityRepository`、点赞/收藏/评论/关注及主页联动；但仍是本地数据，不是云端同步。 |
| 俯仰/偏航引导完全缺失 | **过时/夸大** | 已有 IMU 观测、`CompositionSessionController` 状态机、阈值判断和 Compose 引导 UI；实际效果仍需真机校准，不能把它描述成 AI 直接输出。 |
| Figma UI 完全没有实现 | **不属实** | 相机、登录、社区、个人主页、底栏、滤镜、Pro 和引导 UI 均有实现；但是否逐像素还原设计稿，需要视觉验收，不能仅凭代码宣称闭环。 |
| OTA、Android instrumentation 测试尚未完成 | **属实** | 当前没有 `src/androidTest` 测试文件，也没有模型 OTA 服务；这些属于发布工程待办。 |
| `GuidanceStepSequencer` 是死代码 | **不属实** | 它仍被 `RenderViewModel` 使用；虽然旧流程与新会话控制器并存，需要后续明确职责，不应直接删除。 |
| Zoom `setZoomRatio` 是 fire-and-forget | **部分属实** | CameraX 请求是异步的，但当前代码已用 `ZoomState` 读取实际倍率，并在自动变焦策略中做稳定确认；仍需真机验证镜头切换、画质和速度。 |

## 真正需要真机验收的清单

1. 目标机型上记录 AI 帧处理 p50/p90、丢帧、内存、温度和连续预览时长。
2. 检查前后摄切换、切后台恢复、无权限、无闪光灯和低光场景。
3. 对比自动变焦前后构图、画质、数字裁切和镜头切换观感。
4. 验证主体丢失时是否停止误导，确认人脸框不是人体轮廓的替代品。
5. 真正接后端前，移除固定验证码和演示账号逻辑。
