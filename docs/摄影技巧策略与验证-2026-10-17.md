# 摄影技巧策略与验证

日期：2026-10-17。本报告记录在自动场景、无模板主体规则之上新增的摄影技巧策略。前一阶段见[自动场景与无模板摄影引导](./自动场景与无模板摄影引导-2026-10-17.md)。本地自动验证与完整构建分别记录，不把代码接入等同于真机或人类审美验收。

## 本轮解决的问题

原规则主要回答“主体是否贴边、手机是否端平”。本轮增加“为什么这样取景”的技巧依据，同时区分两种输出：

| 输出 | 当前实现 | 权限 |
|---|---|---|
| 可执行的朝向留白目标 | 在可靠单人朝向证据和有限平移保护条件下，给人物面朝的一侧增加空间 | 进入现有控制器，执行后验证几何与画质；不能绕过 Ready 条件 |
| 可尝试的摄影技巧 | 根据场景、已检测类别及当前画面统计，选择一条有适用条件的简短建议 | 仅空闲预览显示，不生成移动坐标、不控制镜头或拍摄 |

正式 MobileNetV3 检索模型保持不变；学习型审美评分头、相对取景偏好头继续关闭。摄影经验与可测几何改善，不代表模型已经学会普遍的人类审美。

## 1. 可执行技巧：人物朝向留白

### 1.1 观测依据

人脸检测增加眼睛、鼻子和下嘴部关键点。`FacingDirection` 在已经转正、与预览一致的镜像坐标中计算水平头部朝向：

- 必须是有效单人脸；关键点缺失、越界或几何关系不合理时不输出方向。
- 当前检测输入中，脸宽和高均至少 80 像素、眼间距至少 18 像素；要求适中的侧转和有限俯仰，避免正脸、极端侧脸或遮挡时猜测。
- 左右由屏幕中的关键点几何决定，不直接使用 Euler Y 的正负作为显示左右；Euler 角只作为姿态适用范围约束。
- 需要同一被跟踪主体、同一视口的两次一致新采样，间隔为 100～1500ms；缓存、乱序、主体丢失和上下文改变不累计。

这个结果叫“头部朝向”，不是眼睛注视点。脸框也不是完整头发或人体边界，不能据此声称已经测量“头顶留白”或保护了全身。

### 1.2 目标选择

边距保护优先。只有原边距规则选择 KEEP 时，才继续考虑朝向留白：

1. 有稳定、明确的水平头部朝向。
2. 面朝一侧的空隙小于画幅宽度的 0.30，且身后一侧比前方至少多 0.12。
3. 人脸在画面中向朝向相反方向平移 0.12 后，左右仍至少各留 0.13；不满足则保持，不改用变焦或步行补救。

候选始终保留当前构图。选中的技巧目标来源为 `photography_technique_facing_space`，只改变水平位置，维持垂直位置和观测尺度。该阈值是保守工程规则，不是摄影美感的通用评分标准。

`AdaptiveCompositionPlanner` 锁定选中目标。KEEP 期间出现新的适用技巧目标会重新考虑；人物朝向丢失或改变时，旧朝向目标不能继续授权引导。已有目标仍通过 `CompositionSessionController` 输出一个动作，界面副行可说明“朝人物面朝的方向多留一些空间”。不增加“请人物转头”的动作。

### 1.3 执行后验证

沿用几何误差、主体身份、边距、清晰度、亮部细节及曝光可比性检查。目标接近不等于背景更好看；平移之后的新背景必须以实际新画面为准。恶化、无进展、主体或坐标失效继续触发暂停。

Ready 仍要求独立新鲜证据、连续稳定和必要质量条件，拍摄前仍执行 AF/AE 后复核。技巧名字、规则命中和可选提示出现均不授予 Ready。

## 2. 可尝试技巧：按依据选择一条

`TechniqueVisualAnalyzer` 从已有 RGB 分析帧最多采样 96×96 个单元，不新增模型权重、不保存相机 Bitmap、不访问网络。测量包括左右侧区域亮度与边缘密度、主体与周边明暗差、上下区域纹理及左右亮度对称性。

侧区域统计排除扩大的已观测主体框；人像时只排除脸部，并不等于排除了全身。低对比、亮背景、丰富纹理都可能是摄影风格，因此测量只用于选择条件式建议，不自动标为缺陷。左右亮度相似不代表检测到了建筑对称或水面倒影；上下纹理差也不代表检测到了天空和地平线。

| 技巧 ID | 触发依据 | 当前建议与边界 |
|---|---|---|
| `background_bright_attention` | 人像／食物／静物有有效主体；侧边亮区比例明显，主体亮度适中 | “如果侧边亮区抢眼，可以尝试避开它，同时保留主体。”不预测移动后背景 |
| `background_detail_attention` | 上述场景存在有效主体，侧边边缘密度较高 | “想突出主体时，可以试着减少旁边无关的细节。”不把细节直接当杂物 |
| `food_surface_angle` | 稳定识别披萨 | “想突出披萨的配料，可以试试俯拍。”没有自动俯仰、角度目标或完成反馈 |
| `food_layers_angle` | 稳定识别三明治、热狗或蛋糕 | “如果侧面的层次是重点，可以试试从侧面拍。”类别不证明一定有分层 |
| `subject_separation` | 有效主体与周边的平均亮度接近 | “想让轮廓更清楚，可以试试与主体明暗不同的背景。”保留低对比风格选择 |
| `portrait_facing_room` | 人像有有效头部朝向 | “侧脸人像可以在人物面朝的方向多留一些空间。”是技巧说明，不能单独发移动指令 |
| `portrait_background` | 人像场景 | “可以检查头部周围，避开抢眼的线条或杂物。”没有断言检测到了穿头线条 |
| `still_life_corners` | 食物／静物场景 | “可以检查画面四角，减少与主体无关的物件。”没有语义标记每个角落 |
| `plant_outline` | 植物场景 | “想突出枝叶形状时，可以试试更简洁的背景。”没有完整枝叶分割 |
| `landscape_symmetry` | 风景有足够纹理变化，左右亮度相似性较高 | “如果画面有对称结构，可以保留居中，不必强套三分法。”没有检测倒影 |
| `landscape_emphasis` | 风景上部纹理较少、下部纹理较多 | “如果天空平淡、地面更精彩，可以考虑多保留地面。”天空和兴趣区域仍未经语义验证 |
| `urban_leading_lines` | 城市风景场景 | “如果有道路或建筑线条，可以让它们引向想突出的景物。”没有线条方向目标 |
| `landscape_depth` | 自然风景场景 | “如果近处有合适景物，可以让它与远景形成层次。”没有深度或前景分割 |

候选排序先考虑可测的侧边亮区／细节，再考虑食物类别技巧、主体明暗分离，最后使用场景技巧。风景内部优先考虑对称选项、上下取景重点，再到城市线条或自然远近层次。优先级只是选择提示的顺序，不是审美分数。

新提示需在独立新采样中持续至少 500ms。已有提示条件仍成立时，至少保持 4 秒后才允许更高优先级候选替换；条件消失则立即撤回，不等待计时结束。稳定器锁定文字选择，每次有效分析重新绑定当前采样时间，不靠重复缓存续期。

## 3. App 接入与显示约定

`SceneAnalysisObservation.techniqueAdvice` 为可空的 `PhotographyTechniqueAdvice`：

| 字段 | 含义 |
|---|---|
| `id` | 稳定技巧标识，用于避免无意义切换 |
| `title`、`suggestion` | 标题和条件式建议，由策略提供 |
| `evidenceKind` | `MEASURED_IMAGE`、`DETECTED_SUBJECT` 或 `SCENE_RECIPE`；说明依据类型，不是置信概率 |
| `sampledAtMs` | 当前依据的单调采样时间 |
| `expiresAtMs` | 提示依赖证据的最早有效截止；默认不晚于采样后 1500ms |
| `viewportVersion` | 当前预览坐标版本 |
| `reasonCodes` | 可追溯的适用条件与限制；不直接显示工程字段 |
| `requiredAnchorKind`、`requiredTrackingId`、`requiredClassId`、`requiredFacingDirectionX` | 可空／可无依赖的主体绑定；新主体或朝向变化可撤销缓存提示，不能续期原图像证据 |

界面使用一张静态卡，标签为“拍摄技巧 · 可尝试”。只在正常 Idle 预览显示；引导、验证、拍摄、倒计时、结果页、错误、发布、滤镜编辑、Pro 或对焦曝光覆盖时不显示。不新增模式选择器，也不把技巧并排塞入正在执行的方向指令。

场景未知、场景或技巧超过 1500ms、到达技巧的 `expiresAtMs` 截止后、技巧与场景坐标版本不一致时隐藏。依赖脸部的提示同时受人脸采样后 750ms 约束，依赖对象的提示同时受对象采样后 1500ms 约束；更新场景时间不能替旧主体证据续期。`isValidFor` 检查当前主体、类别及必要朝向，`GeometryStage` 可立即清除不再适用的缓存提示。镜头切换通过现有场景失效链路撤销旧内容。UI 仅在证据到期时更新显示，没有定时轮播，也不因为停留了足够久就显示完成。小窗口放不下时隐藏可选卡，保留拍摄控件；无障碍语义保留完整文案。

不需要新增方向动画素材。朝向留白复用控制器已选中的左右移动指令和真实目标；技巧卡没有箭头、完成勾、进度圈或自动拍摄回调。详细交接见[引导动画制作与接入规范 1.3](./引导动画制作与接入规范.md)。

## 4. 摄影来源与工程适用范围

以下来源支持摄影技巧思路，不提供本项目具体阈值，也不能替代执行评估：

- [Nikon：5 Easy Composition Guidelines](https://www.nikonusa.com/learn-and-explore/c/tips-and-techniques/5-easy-composition-guidelines)说明主体朝向一侧留空间、按重点安排地平线，并允许倒影等情形使用居中构图。这里保留“规则有例外”，不把三分法当统一目标。
- [Nikon：Take Better Portraits](https://www.nikonusa.com/learn-and-explore/c/tips-and-techniques/take-better-portraits)建议留意人物背景和头部附近干扰线条。本项目只有条件式背景检查提示，没有宣称识别出了具体穿头物体。
- [Nikon：When Center Composition can Elevate a Portrait](https://www.nikonusa.com/learn-and-explore/c/tips-and-techniques/when-center-composition-can-elevate-a-portrait)讨论居中、背景组织和主体分离。居中与丰富背景都可以有表达价值，本轮不一律拒绝。
- [Canon：Tips for Amazing Food Photography](https://www.usa.canon.com/learning/training-articles/training-articles-list/cooking-with-the-camera-tips-for-amazing-food-photography)按食物形态讨论俯拍和侧拍，并关注背景及画面四角。本项目以稳定类别选择“可以试试”的建议，不照搬可变光圈、镜头焦段或设备能力。
- [Sony：Your Guide to Landscape Photography](https://scene.sonyanz.com/articles-and-resources/your-guide-to-landscape-photography)讨论前中后景层次、引导线和明暗细节。本项目尚无对应语义分割／深度，层次和引导线建议仍带条件。
- [Google：ML Kit Face Detection Concepts](https://developers.google.com/ml-kit/vision/face-detection/face-detection-concepts)说明脸部姿态、关键点及检测限制。当前左右方向来自与预览一致的关键点几何；眼睛关键点不是眼球注视方向，未暴露关键点置信值也不能包装成高置信注视识别。
