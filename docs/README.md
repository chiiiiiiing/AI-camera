## 文档维护约定

- 当前规格只在对应开发文档维护；实验数字只在带日期的报告中记录，索引负责指路。
- 已淘汰教程、旧路线图、重复协作清单和已结束的审查对话从工作树移除；需要追溯时用 Git 历史，不另建一份旧文档副本。
- 本轮清理把旧相机／帧处理／性能／上线教程的有效检查项合并到 Android 开发与验证；旧引导文档由动画接入规范替代，旧模型协作清单由 AI 接入说明替代。
- 原始图片、大型实验、缓存仍在项目内的本地目录，不随文档清理删除。许可证、提示词配置和机器可读验收证据不是废弃文档。
- 修改链接后检查目标文件存在；新增能力区分已实现、待接入和已验证范围。
