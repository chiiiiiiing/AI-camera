## 事实口径

- 当前模型链路：ONNX Runtime Mobile → 512 维 embedding → 模板检索 → App 侧几何与状态机引导。
- 当前检测：ML Kit 人脸框及 NanoDet 物体框；人体轮廓与天空分割尚未接入。
- 当前社区和认证：本地 Room/演示数据，尚未等同于云端生产服务。
- 真机性能、发热、长时间稳定性和 instrumentation 测试仍需验收。
