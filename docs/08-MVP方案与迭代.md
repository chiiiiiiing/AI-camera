## 8.1 MVP 功能范围（V1.0）

**目标**：把"打开相机 → AI 分析场景 → 显示辅助线 → 拍照"这个闭环跑通。

| 功能 | 说明 | 对应文档 |
|------|------|----------|
| ✅ 相机预览 + 拍照 + 保存 | CameraX 基础链路 | [01-相机链路](./01-相机链路.md) |
| ✅ 帧采集 + 模型推理 | ImageAnalysis + ONNX Runtime Mobile | [02-帧处理管线](./02-帧处理管线.md) + [09-AI接入包说明](./09-AI接入包说明.md) |
| ⚠️ 模板检索构图辅助 | embedding + 模板 metadata；不是通用场景分类 | [09-AI接入包说明](./09-AI接入包说明.md) |
| ✅ 构图辅助线渲染 | 至少支持：三分线 + 主体框 + 目标区域 | [04-辅助线渲染引擎](./04-辅助线渲染引擎.md) |
| ✅ 水平仪 | 检测画面倾斜角度 + 显示校正线 | [04-辅助线渲染引擎](./04-辅助线渲染引擎.md) |
| ✅ 快门按钮 + 前后摄切换 | 基础相机控件 | [05-构图引导交互](./05-构图引导交互.md) |
| ✅ 基础设置页 | 辅助线开关、网格类型选择 | [07-上线工程](./07-上线工程.md) |

---

## 8.2 MVP 不做

- ❌ 录像
- ❌ 滤镜/美颜
- ❌ 自动抓拍
- ❌ 多模型融合
- ❌ 拍后裁剪建议（→ V1.1）
- ❌ 社交分享
- ❌ iOS 版本（→ V2.0）

---

## 8.3 推荐迭代路线

### V1.0 — MVP（约 4–5 周）

```
第 1 周：相机链路
  ├── CameraX 初始化 + PreviewView 预览
  ├── 拍照 + MediaStore 保存
  ├── 对焦 / 曝光 / 变焦
  ├── 前后摄切换
  ├── 权限管理
  └── 生命周期管理

第 2 周：帧采集管线 + 模型加载
  ├── ImageAnalysis 配置 + FrameScheduler
  ├── 跳帧逻辑 + 后台线程调度
  ├── YUV→RGB→ByteBuffer 预处理
  ├── ONNX Runtime Mobile 模型加载
  └── GPU Delegate 加速

第 3 周：辅助线渲染引擎 + 水平仪
  ├── CompositionOverlayView 自定义 View
  ├── 三分线 + 主体框 + 目标区域渲染
  ├── 坐标映射工具（含镜像 + 旋转）
  ├── 动画驱动框架（pulse / flow）
  └── 水平仪

第 4 周：场景切换 + 多策略辅助线 + 动效
  ├── 队友模型接入（切换 .tflite + 输出解析）
  ├── 场景识别 → 构图策略切换
  ├── 多种辅助线按场景渲染
  └── 动效打磨

第 5 周：性能优化 + 多设备适配 + Bug 修复
  ├── 性能埋点
  ├── 设备分级适配
  ├── 多设备测试
  └── Bug 修复
```

### V1.1 — 体验增强（约 2–3 周）

- 拍后裁剪建议
- 构图达标反馈（震动/视觉）
- 更多辅助线类型（队友提供设计）
- 模型版本升级（队友提供新版）

### V1.2 — 扩展

- 更多场景覆盖
- 辅助线动画打磨
- 用户偏好学习（是否倾向某种构图）

### V2.0 — 成熟

- iOS 版本
- 高级功能
