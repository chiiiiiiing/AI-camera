# 目标圈停留自动拍摄与方向提示（v5，2026-10-20）

## 行为变化

- 实际拍摄管线统一启用 TargetDwellGate：主体中心位于目标圆内，持续取得约一秒的位置观测，至少三次不同时间的样本后进入 Ready。无需与靶心完全重合。
- 有效位置可以来自实际主体检测或画面纹理跟踪，包括用户手动选定的跟踪区域。手动区域仍明确标记为手动跟踪，不声称模型识别了物体。此规则替代 v4 对画面跟踪一律禁止自动拍摄的限制。
- 离开圆、位置过期或中断超过 750ms、换目标或视口、正在缩放、姿态观测过期或水平未达标时，停留重新计时。重复缓存帧不能累计停留时间。两种位置来源之间正常切换不会重新开始计时。
- 姿态容差沿用当前手持策略，不要求绝对稳定；自动对焦/曝光等待完成后仍重新检查当前位置和拍摄许可。
- 目标区改为圆形，半径以画面短边为单位，绘制与判定同步使用保留目标的实际容差。青色实心点标记“主体中心”，紫色空心点标记“目标位置”。
- 原箭头指向主体在屏幕中应移动的位置，而文字描述相反的手机移动方向。本版连线只表示两点关系，白色箭头和文字统一表示手机取景方向，附说明。镜像前摄单独翻转水平方向。
- 主体显示过渡从 100ms 改为 60ms。保持神经网络原采样节奏，在模型采样间隙增加局部相关跟踪，仅在引导/待拍状态启用，额外跟踪间隔至少 100ms；包含预处理的耗时超过 30ms 时，下一次至少间隔 250ms。这是调度上限，不代表真机保证达到 10fps，也不等于温度传感器控制。
