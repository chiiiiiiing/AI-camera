原文档隐含的理解更接近“认证优先”，但当前产品流已经调整为：

1. 冷启动先显示带 Logo 的 Splash

## 2. 当前 Android 工程已经实现的内容

### 2.1 相机拍摄页

已实现：

- 黑色相机上下控制区
- 真实 CameraX 预览
- 三分线网格
- 四角目标参考框
- 左上模式切换：
  - 静物模式
  - 风景模式
  - 人像模式
- 模式选中态：
  - 当前模式 icon 为粉色
  - 其他 icon 为白色
- 粉色快门按钮
- 最近照片缩略图
- 前后摄切换
- 底部三个目的地入口：
  - 相机
  - 推荐
  - 个人主页

### 2.2 引导系统

当前引导已经拆成 5 个稳定视觉家族：

| 状态 | 当前实现 |
|------|----------|
| NONE | 低干扰网格/目标框 |
| TRANSLATION | 目标太阳 + 十字准心 + 平移箭头 |
| AXIS_ROTATION | 渐隐轴线 + 透视弧线 + 路径箭头 |
| PLANAR_ROTATION | 手机轮廓 + 外圈旋转弧 |
| SUBJECT | 人物轮廓 + 锚点 |

额外补充：

- 已支持 `WRONG_DIRECTION`
- 已支持 `NEAR`
- 已支持 `ALIGNED`
- 已支持人像模式“两阶段引导”：
  1. 先整体平移对齐
  2. 再出现静态人物轮廓

### 2.3 登录/注册页
